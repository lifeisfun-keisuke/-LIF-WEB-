LIF-Hub 利用規約

2026年10月23日 施行

この利用規約（以下「本規約」）は、株式会社LIF（以下「当社」）が提供するクラウドサービス「LIF-Hub」（以下「本サービス」）の利用条件を定めるものです。本サービスを利用するすべての方は、本規約に同意したうえで利用するものとします。

第1章 総則

第1条（定義）

  1. 「本サービス」とは、当社が「LIF-Hub」の名称で提供する、LINE公式アカウントの顧客管理・メッセージ配信等のマーケティング管理機能を備えたクラウドサービスをいいます。
  2. 「契約者」とは、本規約に同意し、当社所定の方法で本サービスの利用を申し込み、当社が承諾した法人または個人事業主をいいます。
  3. 「利用者」とは、契約者が本サービスの利用を許可した役員・従業員その他の者をいいます。
  4. 「アカウント」とは、利用者が本サービスにログインするためのメールアドレス、パスワードその他の認証情報をいいます。
  5. 「外部サービス」とは、LINE公式アカウント、Messaging APIその他、本サービスと連携して利用する第三者のサービスをいいます。
  6. 「契約者データ」とは、契約者または利用者が本サービスに登録・送信したデータ、および外部サービスとの連携により本サービスに取り込まれたデータ（友だち情報、メッセージ履歴等を含みます）をいいます。

第2条（本規約の適用）

  1. 本規約は、当社と契約者・利用者との間の本サービスの利用に関わる一切の関係に適用されます。
  2. 当社が本サービス上やウェブサイトで掲載する料金表・各種ルール・注意事項は、本規約の一部を構成します。本規約とそれらの内容が異なる場合は、それらの内容が優先します。
  3. 契約者は、利用者に本規約を守らせるものとし、利用者の行為について自らの行為として責任を負います。

第2章 契約・料金

第3条（申込みと契約の成立）

  1. 本サービスの利用を希望する者は、本規約に同意のうえ、当社所定の方法で申し込むものとします。
  2. 利用契約は、当社が申込みを承諾し、アカウントを発行した時点で成立します。
  3. 当社は、申込内容に虚偽がある場合、過去に本規約違反があった場合その他当社が不適当と判断した場合、理由を開示せずに申込みをお断りすることがあります。

第4条（初期無料枠および無料トライアル）

  1. 当社は、サービス開始にあたり、先着で当社が別途定める人数の契約者に対し、利用料金を無料として本サービスを提供します（以下「初期無料枠」）。初期無料枠の人数および受付状況は、当社のウェブサイトに掲載します。
  2. 初期無料枠の契約者は、当社が有料プランへの移行を通知するまで、無料で本サービスを利用できます。当社が有料プランへの移行を求める場合は、移行日の30日前までに条件を通知し、契約者が移行日までに解約しない場合は有料契約に移行するものとします。
  3. 初期無料枠の定員に達した後に新たに申し込む契約者は、契約成立日から14日間、本サービスを無料で利用できます（以下「無料トライアル期間」）。無料トライアル期間の利用は、1契約者につき1回限りとします。
  4. 無料トライアル期間の開始時に、契約者は支払いに利用するクレジットカードを登録するものとします。
  5. 無料トライアル期間の終了日までに第7条の解約手続きを行わない場合、無料トライアル期間の終了日の翌日から自動的に有料の利用契約に移行し、登録されたクレジットカードで利用料金の決済が行われます。
  6. 当社は、無料トライアル期間が終わる前に、有料契約へ移行する日と料金をメール等でお知らせします。

第5条（利用料金と支払い）

  1. 利用料金は月額制とし、金額は当社のウェブサイトに掲載する料金表に定めるとおりとします（消費税込み）。
  2. 支払い方法は、当社が指定する決済代行事業者（Stripe）を通じたクレジットカード決済とします。当社はカード番号を自ら保持しません。
  3. 利用料金は、有料契約の開始日に初回分を、以後は毎月同じ日に翌1か月分を前払いで決済します。
  4. 支払済みの利用料金は、本規約に定める場合を除き返金しません。月の途中で解約した場合も、日割りによる返金は行いません。
  5. LINE公式アカウントの月額料金・メッセージ配信料金など外部サービスの利用料は利用料金に含まれず、契約者が各事業者に直接支払うものとします。
  6. 決済ができなかった場合、当社は契約者に通知のうえ、支払いが確認できるまで本サービスの全部または一部の利用を停止することがあります。
  7. 当社は、利用料金を変更する場合、変更の30日前までに契約者に通知します。

第6条（契約期間と自動更新）

  1. 有料契約の期間は、決済日から1か月とします。
  2. 契約者が解約手続きを行わない限り、契約は同じ条件で1か月ごとに自動で更新されます。最低契約期間はありません。

第7条（解約）

  1. 契約者は、本サービスの管理画面内のマイページから、いつでも解約できます。
  2. 解約した場合も、支払済みの契約期間の最終日まで本サービスを利用でき、次回以降の請求は行いません。
  3. 無料トライアル期間中に解約した場合、利用料金は一切発生しません。初期無料枠の契約者が解約した場合も同様とします。
  4. 当社は、契約終了日から30日を過ぎた契約者データを削除できるものとします。契約者は、必要なデータ（友だち一覧のCSV等）を契約期間中に自ら保存するものとします。

第3章 利用上のルール

第8条（アカウントの管理）

  1. 契約者および利用者は、自己の責任でアカウントを管理し、第三者に使用させたり、貸与・譲渡したりしてはなりません。
  2. アカウントを使って行われた操作は、そのアカウントを持つ利用者によるものとみなします。
  3. アカウントの不正使用やそのおそれに気づいた場合は、ただちに当社に連絡し、当社の指示に従うものとします。

第9条（外部サービスの利用）

  1. 契約者は、自らの責任と費用でLINE公式アカウントその他の外部サービスを用意し、その利用規約・ガイドラインを守るものとします。
  2. 外部サービスの仕様変更、提供停止、アカウントの停止・凍結などにより本サービスの機能が使えなくなった場合、当社は責任を負いません。
  3. 本サービスからのメッセージ配信は、契約者のLINE公式アカウントから契約者の名義で行われます。配信内容とその結果については、契約者が責任を負います。

第10条（禁止事項）

契約者および利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

  1. 法令、公序良俗、外部サービスの利用規約に違反する行為
  2. 受信者の同意のない広告・宣伝の送信その他、特定電子メール法等に反する配信
  3. 虚偽・誤解を招く表示、景品表示法に反する表示を含む配信
  4. 第三者の知的財産権、プライバシー、名誉その他の権利を侵害する行為
  5. 本人の同意なく取得した個人情報を登録・利用する行為
  6. 本サービスのサーバーやネットワークに過度な負荷をかける行為、不正アクセス、リバースエンジニアリング
  7. 本サービスを第三者に再販売・貸与する行為（当社が書面で承諾した場合を除きます）
  8. 反社会的勢力への利益供与その他の協力行為
  9. その他、当社が不適切と判断する行為

第11条（契約者データの取扱い）

  1. 契約者データの権利は契約者に帰属します。
  2. 当社は、契約者データを本サービスの提供、障害対応、サポート、機能改善のために必要な範囲でのみ利用し、法令に基づく場合を除き第三者に開示しません。ただし、個人や契約者を特定できない形に加工した統計情報は、本サービスの改善に利用することがあります。
  3. 当社は、本サービスの運営に必要な範囲で、クラウドサーバー等の外部事業者に契約者データの保管を委託することがあります。
  4. 契約者は、友だち等の個人情報を個人情報保護法その他の法令に従って取得・利用する責任を負います。
  5. 当社による個人情報の取扱いは、別に定めるプライバシーポリシーによります。
  6. 当社は契約者データの安全な保管に努めますが、契約者は重要なデータを自ら定期的に保存するものとします。

第4章 サービス運営と責任

第12条（サービスの変更・停止・終了）

  1. 当社は、本サービスの内容を変更・追加することがあります。契約者に重大な影響がある変更は、事前に通知します。
  2. 当社は、次の場合、事前の通知なく本サービスの全部または一部を一時停止することがあります。
    1. システムの保守・点検・更新を行う場合
    2. 停電、天災、障害、外部サービスの停止などで提供が困難な場合
    3. その他、当社がやむを得ないと判断した場合
  3. 当社は、本サービスの提供を終了する場合、終了の90日前までに契約者に通知します。

第13条（当社による契約解除）

当社は、契約者が次のいずれかに該当する場合、事前の通知なく本サービスの利用を停止し、または契約を解除できます。

  1. 本規約に違反し、是正を求めても相当の期間内に改めない場合
  2. 利用料金の支払いを怠った場合
  3. 申込内容に虚偽があった場合
  4. 反社会的勢力であること、またはそれと関係があることが判明した場合
  5. その他、当社が契約の継続を不適当と判断した場合

第14条（保証の否認と免責）

  1. 当社は、本サービスが契約者の特定の目的に合うこと、配信により特定の売上や集客の成果が出ること、障害や不具合が生じないことを保証しません。
  2. 当社は、第9条に定める外部サービスに起因する損害について責任を負いません。
  3. 当社の責めに帰すべき事由により契約者に損害が生じた場合、当社の責任は、損害が生じた月の前月までの直近12か月間に契約者が当社に支払った利用料金の総額を上限とし、逸失利益その他の間接損害は含みません。
  4. 前項の制限は、当社に故意または重大な過失がある場合には適用しません。

第15条（反社会的勢力の排除）

契約者は、自らおよびその役員が、暴力団その他の反社会的勢力に該当しないこと、および将来にわたって該当しないことを表明し、保証します。

第16条（規約の変更）

当社は、民法の定型約款の変更の定めに従い、本規約を変更できます。変更する場合は、変更後の内容と効力が生じる日を、効力が生じる日の相当期間前までに当社のウェブサイトへの掲載やメール等でお知らせします。

第17条（権利義務の譲渡禁止）

契約者は、当社の書面による承諾なく、利用契約上の地位や権利義務を第三者に譲渡し、または担保に入れることはできません。

第18条（準拠法・管轄裁判所）

本規約は日本法に準拠します。本サービスに関する紛争は、東京地方裁判所を第一審の専属的合意管轄裁判所とします。
